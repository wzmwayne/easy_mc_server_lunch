🍱 Easy MC Server Lunch

开发者: wzmwayne 和 iFlow CLI

📦 系统要求

  • Termux (Android) 或 Linux系统
  • Python 3.7+
  • Java 17+ (自动安装)

🚀 一键安装

复制以下命令到终端执行：

bash -c "$(curl -fsSL https://wzmwayne.github.io/easy_mc_server_lunch/install.sh)"

📖 使用说明

  • 安装完成后，运行 ./start.sh 启动服务器
  • 访问 http://localhost:5000 打开Web界面
  • 运行 ./stop.sh 停止服务器
